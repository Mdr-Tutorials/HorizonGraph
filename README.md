# HorizonGraph

面向中文学生与从业者的全栈科技与 AI 产业知识图谱。

**北极星**

1. 认知重于检索——拓扑探索破除"不知道自己不知道"
2. 全栈全链穿透——理论 → 内核/硬件 → 框架 → 大模型/商业实体
3. 真实网状拓扑——多归属、竞争、演进，如实反映技术生态
4. Build-Time Rich, Runtime Free——图计算全在构建期，运行期零成本托管
5. 活态演进——保留技术血缘与历史脉络

**快速上手**

```bash
pnpm install
pnpm gen        # 从 contracts/types.json 生成 TS 类型
pnpm validate   # 八项 CI 校验
```

**架构入口**：`docs/decisions/`（ADR 0001–0017）· `contracts/`（Schema 唯一来源）
