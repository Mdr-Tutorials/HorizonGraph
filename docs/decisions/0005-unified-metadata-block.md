# ADR-0005：统一节点元数据块

- 状态：已接受
- 日期：2026-08-29

## 背景

v3.0 的 status 是无时间快照，而目标用户（学生与从业者）的核心诉求之一是"这技术现在还活着吗、什么时候的事"；AI 侧节点高频过期；纯静态搜索（Pagefind / MiniSearch 类）缺少动态权重来源。

## 决策

所有类型节点统一增加元数据块（不做按类型打补丁）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `first_released` | 否 | ISO 日期 |
| `deprecated_at` | 否 | ISO 日期，status 为 deprecated 时必填 |
| `last_reviewed` | 是 | ISO 日期，数据核对时间，页面展示"核对于 YYYY-MM" |
| `importance` | 是 | 1–5 手评热度，服务搜索排序与首页推荐 |

importance 锚定标准写入 conventions：5 = 教学主线必讲；3 = 生态常见；1 = 长尾。可另由图的入度派生参考值做校准，但正本为手评。

## 后果

正面：status 获得时间锚点；last_reviewed 同时是维护信号与用户信任信号；importance 以极低成本补齐静态搜索的排序信号。
负面：每节点录入成本 +2 必填字段；手评主观，依赖锚定标准维持一致性。
