# ADR-0027：整领域内容扩展与工程路径

- 状态：已接受
- 日期：2026-10-01

## 背景

ADR-0026 补齐了八块既有领域的基础概念，但地理空间、医疗、生物、电力、材料、模拟电子、工业自动化、运筹优化、科学计算、信号处理、信息论和知识工程仍缺少成体系的入口。一些领域已有工具节点，却无法沿图谱探索其数据模型、方法、标准和应用条件。

## 决策

1. 以十二个领域为一批，建立基础概念、主要方法、标准与数据、实际工具及应用之间的可遍历路径。范围包括 GIS 与遥感、医疗信息学、生物信息学、电力与能源、材料与计算化学、模拟与射频电子、工业自动化、运筹优化、科学计算与 CAD/CAM/CAE、信号与媒体处理、信息论、知识表示与语义网。每块的节点清单和来源记录于批次文档。
2. domains 从 0.3.0 升至 0.4.0，新增十九个领域标识，总计五十三个。领域轴允许多归属；遥感与地理空间、数学优化与运筹、生物信息与计算生物等主题分别登记，以便表达交叉知识。
3. ontology 从 0.9.0 升至 0.10.0，新增十二个概念分类，总计七十个。本批新分类继承 theory，适用 concept。实际软件、数据制品、标准、语言、组织和度量仍按原有 EntityType 与对应本体分类建模。物理信噪比等度量归 metric，不挂概念分类。
4. ecosystems 从 0.1.0 升至 0.2.0，新增十一个子生态，总计七十五个。既有十个宏观生态根继续封闭；领域相关的工程共同体挂到已有宏观根，允许真实跨生态归属。
5. 保持现有 id。功率变压器与 Transformer 模型、物理信噪比与认知语境的“信噪比”分别建节点。DFT 等缩写允许同名，依靠 id、中文显示名、摘要和分类消歧。RDF 数据模型建 concept，RDFS、OWL、SPARQL 等按语言身份建模；JSON-LD、Turtle 等交换格式按既有 protocol 契约登记。
6. 正文采用主题对应的一手资料：标准机构、项目官方文档、研究作者教材或原始论文。记录检索日期并标为 ai_draft。正文解释适用范围，例如标准定义与实际互操作、数值收敛与物理正确性、分子模拟与电子结构计算、逻辑蕴涵与数据校验之间的区别。
7. 继续使用原有二十九种关系，不增加泛化的“相关”边。uses 必须说明实际采用的模型、方法或格式；implements 用于具体工件实现规范或概念；depends_on 仅表达真正依赖。可选后端、插件或求解路线在 context 中限定，避免把可选配置写成所有部署的要求。对称边仍按规范方向单份存储。
8. 每个新增节点至少具有一条非分类的入边或出边。实质扩写旧节点时补充来源、领域与工程连接，并保留稳定身份。完整构建统一重生成快照、搜索索引、邻域、正文分块、WASM 与离线发布清单；使用实际构建数据检查所有新增节点的搜索和正文读取。

## 后果

十二个领域可以从主题、分类与生态入口进入，并继续探索已有的数学、机器学习、数据库、网络、硬件及安全知识。扩展兼容当前查询引擎与静态发布流程。ai_draft 表示资料经过本次研究与自动化校验，仍保留后续人工审校的状态边界。

批次范围、完整节点清单、来源与验证见 [十二个领域补全记录](../content-domains-2026-10.md)。
