# ADR-0007：内容语言政策——中文唯一正本

- 状态：已接受
- 日期：2026-08-29

## 背景

summary / description 为单语字段。中英抉择若推迟，后续从 string 改双语结构化对象是全量重构，此刻改是零成本决策。

## 决策

1. `name` 保留英文/官方原名（最权威命名）
2. 中文译名、俗称一律进 `aliases`（检索层做权重匹配，与搜索解耦原则一致）
3. `summary` / `description` 以中文为唯一正本，不设双语字段
4. 本决定为长期政策；若未来需要双语，须以新 ADR 显式取代本决策，不做字段级渐进改造

## 考虑过的替代方案

双语结构化对象（summary: {zh, en}）：录入成本翻倍，目标用户为中文学生与从业者，双语价值不足，拒绝。

## 后果

正面：录入成本最小，字段结构保持简单，与用户群匹配。
负面：放弃英文正文受众；英文消费仅靠 name / aliases / official_site。
