# ADR-0012：许可证——数据 CC BY-NC-SA 4.0，代码 MIT

- 状态：已接受
- 日期：2026-08-29

## 背景

社区共建知识资产，开放前必须定许可。数据（节点、词表、派生产物）与代码（build、CI、前端）性质不同，分别授权。

## 决策

- **数据**：CC BY-NC-SA 4.0（署名—非商业—相同方式共享）
- **代码**：MIT

## 已知代价（记录在案）

- NC 边界模糊：带广告的技术博客、付费课程/训练营、企业内训是否属商业用途存在解释空间，会抑制部分再利用。目标用户含付费教育场景，**须随 LICENSE 附项目方解释口径（FAQ）**，明确边界认定（如允许教学引用、禁止未授权商业集成与转售），否则社区因不确定而不敢引用
- NC 与开放数据生态（Wikidata 等）不兼容，内容无法被主流开放数据集吸收
- SA 保证分叉同开放，防闭源分叉与商业白嫖
- CC 不适用于软件，故代码走 MIT；数据库权利未由 CC 显式覆盖，实用上按内容许可执行

## 后果

正面：社区共建资产受 Share-Alike 保护；代码可被任意复用。
负面：上述 NC 代价成立，以解释口径 FAQ 缓解。
