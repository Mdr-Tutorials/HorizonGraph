# ADR-0017：version_of 切片关系

- 状态：已接受
- 日期：2026-08-29

## 背景

版本节点（C++23、GLM-4.5）挂向母体的边原只能在 part_of 与 extends 间二选一，处于 0003 点名的语义重叠区。节点形态实际分化为三类：集合（分类骨架）、普通节点、版本切片，切片缺显式标记。

## 决策

1. 新增 `version_of` 关系：切片方持有，指向母体；源与目标同 type；不新增 EntityType、不加标记字段，切片性由边推导
2. 版本节点先过 0008 独立生态位判定，通过才配 version_of
3. 版本页渲染为母体差异视图：新增能力按 part_of 聚合，时间线按 first_released 排序；版本先后关系由日期承担，不设后继边，不滥用 deprecated_by
4. 搜索中持有 version_of 的节点折叠于母体名下，不与母体并列竞争
5. 与近邻关系的分界：part_of 是空间组成，version_of 是时间切片；extends 是超集扩展，version_of 是母体在时间轴上的投影

## 后果

正面：四重重叠区（depends_on / bases_for / embeds / part_of）高频的版本场景被单独收割，录入歧义消除；UI 与搜索获得统一信号。
负面：part_of 与 version_of 仍存边界案例（标准与特性的挂载方向），试点复核。

## 关联

0003（关系规格表）、0008（版本判定）、0010（搜索降权同构）
