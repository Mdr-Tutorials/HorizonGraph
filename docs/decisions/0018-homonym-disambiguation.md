# ADR-0018：同名消歧——id 承担身份

- 状态：已接受
- 日期：2026-08-29

## 背景

名称全局唯一把同词同物与同名异物混为一谈。多义词（GLM 大模型与统计模型、Spark、Swift/SWIFT）是正常现象。曾评估"冲突失败 + 登记承认制"方案，被否——每个节点已有唯一 id，身份区分天然存在，登记与失败都是多余机制。

## 决策

1. id 跨全图绝对唯一，承担节点身份；id 冲突即 CI 失败
2. name / abbreviation / aliases 完全自由，允许任意冲突，不设登记、不设失败
3. 名称易混时 slug 自带限定词：`glm-llm-zhipu`、`glm-stat-model`、`apache-spark`（写入 conventions）
4. 检索层动态匹配：同名词返回全部命中，以 type、生态、summary 区分——与 Schema 搜索解耦原则一致
5. 重复实体（同词同物）由人工审校合并；slug 与别名近似检测列入百万级批量管线（ADR-0011 消歧环节）

## 后果

正面：零机制成本，消歧回归检索层本职，与搜索解耦原则完全一致。
负面：重复实体不再有名称级防线，依赖审校与后续批量检测。
