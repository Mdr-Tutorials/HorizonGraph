# ADR-0024：职业扩展中的评估偏差与母子公司关系

- 状态：已接受
- 日期：2026-09-20

此次补齐职业、量化、招聘机制、薪酬和职业发展内容时，需要表达两个现有关系无法准确承载的事实：Google 经 XXVI Holdings 归属于 Alphabet；前视偏差可能使回测结果失真。

新增 subsidiary_of，规范方向为子公司到直接母公司，源和目标均限 organization，反向展示为“子公司”。它与公司更名、项目治理、产品提供和企业合称分别建模。Google 指向 XXVI Holdings，后者指向 Alphabet；不把 Alphabet 填入 Google 的别名，也不另存跨过中间公司的直接边。

新增 can_bias，规范方向为偏差机制到受影响的评估方法或指标，源限 concept，目标限 concept 或 metric，反向展示为“偏差来源”。它表达有条件的结果失真，不能用作泛化关联，也不能替代 uses 或 governs。

两类边均要求非空 context，复用关系契约驱动的类型、目标来源和语境校验。构建仍只存规范方向，前端依据同一契约派生反向视图。

本体新增“量化研究概念”“量化绩效指标”“职业发展”三个导航分类。指标继承 metric 类型，职业与研究概念继承 concept 类型。岗位头衔和缩写以职责为单位组织；薪酬形式及职业管理流程分别说明适用范围。

正文来源用于界定含义。GitLab 等公司的公开流程只是具体实例，不据此规定所有公司的面试顺序、薪酬政策或晋升条件。公司历史参考 Google 的官方重组公告；控股链参考 FCC 2026 年公开通知与 Alphabet 2025 年末主要子公司清单，并注明文件中的信息基准日。前视偏差以 QuantConnect 的回测与实盘差异说明为依据。
