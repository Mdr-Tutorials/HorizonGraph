# ADR-0008：版本实体判定——独立生态位标准

- 状态：已接受
- 日期：2026-08-29

## 背景

model_family（GLM、GPT、Llama）迭代以月计。GLM-4 与 GLM-4.5 是同节点还是分节点，不定规则则 AI 侧节点数量一年内失控。

## 决策

判定标准：**有独立生态位才开新节点。**

满足任一条即独立成节点：

- 拥有自己的关系边集合（生态位确实不同）
- 有独立官方文档或发布物
- 教学叙事上需要并列对比

否则版本作为节点内字段或描述内容处理。

边界案例记入 conventions 由维护者裁决。典型先例：C++20 相对 C++ 关系边密集（特性挂载、part_of），符合标准，独立成节点；GLM-4.5 相对 GLM-4 若仅参数与能力差异、共享生态位，则并入 model_family 节点。

## 后果

正面：节点数量受控；图密度反映真实生态差异而非版本号差异。
负面：判定存在主观空间；节点内版本字段的具体形态暂不强制，试点后可细化。
