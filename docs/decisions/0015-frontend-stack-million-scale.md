# ADR-0015：前端技术栈——百万级终态，无分层

- 状态：已接受
- 日期：2026-08-29

## 背景

ADR-0011 已定基础设施百万级单一终态；愿景第 4 条明确"端侧 WASM 引擎"。邻域呈现原为"语义面板 + 力导向画布"双表示，画布因高密度边渲染不可读被否——**邻域单表示：分块平铺**。

## 决策

### 1. 页面模型：结构二分，非规模分层

- **站点页**（首页、生态页、分类页、文档，数量有限、随契约演变）：静态预渲染
- **节点页**（数据平面全部词条）：一律客户端渲染，从打包 bundle 现算邻域分块，**永不生成 per-node HTML**——与节点数量无关

404.html 作壳兜底 SPA 路由（GitHub Pages 无 fallback）。

### 2. 框架与呈现

- **Astro**：站点页静态生成，词条视图作为全功能岛屿
- **Vue 3**：岛屿内 UI（中文社区人才池最大，Astro 一等支持）
- **邻域单表示——分块平铺**：词条页邻域按关系方向分块（正向关系名 / 反向 inverse_display），组内 importance 降序，超过阈值折叠；不渲染画布、不画边
- 引用态词条只显示全称与第一简称；完整信息只在词条自身页面。无装饰边框、无底色面板、无意义文案，结构靠间距与字重

### 3. WASM：第一天即有

- **Rust + wasm-bindgen**，两个模块：bundle 解码器（压缩边表 → typed array）与搜索打分器（CJK 模糊匹配与加权）
- UI 逻辑保持 TypeScript；WASM 只承担 codec 与 scorer
- wasm 构建产物由 deploy.yml 随 bundle 一起产出

### 4. 搜索与离线

- 搜索分片 fragment 按需加载；命中后客户端用 L0 元数据重排（importance 加权、分类节点降为导航分区、版本折叠于母体）
- **Service Worker 第一天即有**：shell 与 bundle 缓存，站点可离线运行

### 5. 其余约定

Tailwind CSS；TS 类型由 tools/gen 从 types.json 生成（tools 与 web 共享生成物）；URL 即状态（词条走路径、邻域过滤走 query）；术语拉丁字体 Fredoka、全局英文 Mona Sans（拉丁子集自托管）；术语中文 HarmonyOS Sans SC 以**构建期子集化**打包——charset 随数据文本自动派生，双字重约百 KB，不违反体积预算；全局中文保持系统字体栈。

## 已知代价

- 长尾节点页无服务端 HTML：Google 可索引，百度基本不可见。分类页与生态页作为可索引入口。若百度长尾流量日后成为硬需求，另立 ADR
- Rust 工具链提高贡献门槛（WASM 模块范围已压至最小以缓解）
