# ADR-0013：CI 校验套件——强制平面落地

- 状态：已接受
- 日期：2026-08-29

## 背景

ADR-0001 确立强制平面。本项目贡献走单一低门槛通道（任何人可 PR 数据与契约文件），CI 是唯一结构守门员：规则缺口即数据缺口。

## 决策

校验项清单（随对应 ADR 演进同步维护）：

1. **结构**：按 types.json 适用性矩阵校验每节点的必填/可选/禁填字段（ADR-0002）
2. **标识**：slug 规范（ADR-0006）、id 唯一；name/abbreviation/aliases 允许同名，不入校验（ADR-0018）
3. **边完整性**：domain/range 合法、目标存在（无死边）、无镜像与重复边、对称边单向存储（ADR-0003）
4. **分类骨架**：分类边目标必须存在于本体文件；数据平面文件被分类边指向即失败（ADR-0010）
5. **词表**：sub_ecosystems / domains / tags 未登记值零容忍；tags 快照漂移检测（ADR-0004）
6. **元数据块**：last_reviewed / importance 存在与格式；deprecated 节点必须带 deprecated_at（ADR-0005）
7. **许可**：源码文件许可头与 MIT 一致（ADR-0012）
8. **构建可重复**：派生产物哈希稳定，增量构建后与全量构建产物一致

执行模式按百万容量设计：PR 触发增量校验（仅变更节点及其邻接），定期全图校验（流式）。

## 后果

正面：结构审查完全自动化，人工 review 只看内容质量；单一贡献通道下数据质量的下限由机器兜底。
负面：CI 是唯一守门员，清单须与 ADR 严格同步，遗漏即放行。
