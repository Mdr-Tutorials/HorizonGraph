# ADR-0004：受控词表与登记模式

- 状态：已接受
- 日期：2026-08-29

## 背景

开放字符串列表无受控词表，必然漂移（"Systems Programming" / "System Programming" / "系统编程" 并存）。meta_concept 层实质是全图分类骨架的本体，却以普通数据节点形态存在。

## 决策

1. 契约目录 `vocab/`：domains、ecosystems、tags 各一份注册表文件，手写登记全部合法值（ecosystems 为树形注册表，见 ADR-0016）
2. 登记制：新词必须与数据 PR 同步登记进注册表，CI 对未登记词零容忍
3. 漂移检测走双向 CI 校验：数据中出现未登记值即失败；登记项连续多个校验周期未被任何节点引用则告警。不向仓库提交任何派生快照（ADR-0014）
4. meta_concept 本体独立成文件（`contracts/ontology.json`）并带语义化版本号；本体变更走显式 PR，随数据顺手增删会被 CI 拒绝

## 后果

正面：词表漂移在 CI 阶段被拦截；meta_concept 变更可见、可追溯；仓库无派生文件。
负面：贡献摩擦增加（一次改动动两个文件）；需周期性修剪低频词，是长期治理成本。
