# 数据许可 FAQ（NC 边界解释口径）

本文件是项目方对 CC BY-NC-SA 4.0 中"非商业（NC）"边界的解释口径，供使用者参考；许可证法律文本为最终依据。

## 允许（满足署名 + 相同许可 + 非商业三条件）

- 教学、学习、研究中的引用与展示
- 个人博客、技术文章的引用与摘录（含带广告的个人博客）
- 开源项目内嵌数据子集（其分发亦须 CC BY-NC-SA）
- 学术论文引用

## 需要事先授权

- 收费课程、训练营、企业内训中集成或分发本数据
- 商业产品、SaaS 服务内嵌本数据或其派生切片
- 转售、汇编出版、闭源分叉
- 任何以盈利为主要目的的系统性使用

## 署名方式

页面页脚或数据分发处注明：数据来源 HorizonGraph，链接指向本仓库，并标注 CC BY-NC-SA 4.0。
