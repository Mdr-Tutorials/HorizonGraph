## 当前资料及适用边界

- 产品状态按具体交付面限定。Antigravity 2.0 与独立 IDE 分开，本地 SDK 和托管 agent 的预览状态不能由品牌 GA 推导。[Google 文档入口](https://www.antigravity.google/docs/home)、[本地 SDK](https://www.antigravity.google/docs/sdk/overview)、[托管 agent](https://ai.google.dev/gemini-api/docs/antigravity-agent)分别支撑其身份；托管预览不支持的工具、输入及结构化输出能力不会从 IDE 或 SDK 转移过去。
- 桌面 macOS/Linux 的新权限系统、Windows 的旧设置、CLI 与 SDK 策略接口各有条件。URL 读取与页面交互授权分开，独立 Chrome profile 仍可保存自身登录状态；上下文隔离、浏览器状态隔离和操作系统沙箱分别说明。[权限](https://www.antigravity.google/docs/permissions/)、[沙箱](https://www.antigravity.google/docs/sandbox/)不作为所有组件的统一安全保证。
- MCP 当前正式 2026-07-28 核心的自包含请求与 MRTR 按版本记录，旧版初始化和会话交互保留明确语境。Tasks、Skills、Apps 等可选扩展的规范身份和客户端实际支持分开。[当前变更记录](https://modelcontextprotocol.io/specification/2026-07-28/changelog)是兼容性边界的直接来源。
- Agent Skills 格式与宿主便利行为分开，Agent Plugins 1.0.0 便携规范与 Antigravity 原生配置分开；插件规范不统一所有 hooks/rules/subagents。旧 IDE workflows 公告于 2026-10-19 停止工作，复核日 2026-10-08 仍处过渡阶段。[迁移说明](https://www.antigravity.google/docs/migration/workflows-to-skills/)不被写成已经发生的全部宿主行为。
- A2A 表达远程代理之间的交互；Agent Client Protocol 表达编辑器与编码代理的接口，与另一个 Agent Communication Protocol 缩写消歧。LSP 基于 JSON-RPC，DAP 自有消息结构，不从名称相似推导实现兼容。
- 会话历史、状态、长期记忆、上下文压缩和执行检查点各有职责。子代理上下文独立不证明其工具和权限也独立；恢复状态不自动保证外部副作用恰好执行一次。结构化输出的格式符合与语义正确分别验证。
- 浏览器观察、定位、动作、等待、隔离及执行记录各有机制。可访问性快照、DOM 快照、截图与坐标操作不是同一观察方式。官方宣称浏览器操作能力不证明 Antigravity 内部采用 Playwright 或 CDP；trace 播放也不保证确定重执行。
- 评估数据集、执行环境、判定规则、成功率、预算、成本和轨迹分别记录。HumanEval、SWE-bench、WebArena 与 OSWorld 的不同版本任务和环境不混用；pass@k 与 pass^k 区分采样成功和重复可靠性。证据、测试输出与产物审查不等于全局正确性保证。
- Google Agent Platform 的连续品牌与托管 runtime、Gemini API、Interactions API 和本地 SDK 分开。Gemini CLI 的特定消费订阅入口迁移不代表整个 OSS 项目停止；Firebase Studio 的停止新增与计划终止日期不套用给 Firebase 后端；Jules、Code Assist 与 Antigravity 各自按官方状态建档。
